# Toko NASA — Website Toko Online

Website katalog toko responsif, menggunakan HTML, CSS, dan JavaScript biasa. Bisa dibuka langsung di browser atau diunggah ke hosting statis seperti GitHub Pages, Netlify, atau Vercel.

## Fitur
- Tampilan responsif untuk HP dan desktop
- Katalog produk dan kategori
- Pencarian dan pengurutan produk
- Modal detail produk
- Keranjang belanja dengan penyimpanan browser (`localStorage`)
- Ubah jumlah, hapus produk, dan kosongkan keranjang
- Checkout menyusun ringkasan pesanan untuk WhatsApp
- Navigasi mobile dan notifikasi interaktif

## Cara memakai
1. Ekstrak file ZIP.
2. Buka `index.html` di browser untuk mencoba website.
3. Buka `app.js` menggunakan editor teks.
4. Ubah `WHATSAPP_NUMBER` di bagian paling atas menjadi nomor admin, format internasional tanpa tanda `+`, spasi, atau tanda hubung. Contoh Indonesia: `6281234567890`.
5. Sesuaikan nama toko, daftar produk, harga, deskripsi, kategori, emoji, dan warna pada array `products` di `app.js`.
6. Unggah seluruh isi folder ke hosting pilihan.

## Penting
- Produk dan harga di dalam paket ini adalah **data contoh**, bukan daftar resmi atau harga terkini dari perusahaan NASA.
- Template ini tidak mengklaim sebagai situs resmi atau berafiliasi dengan perusahaan/brand NASA. Gunakan logo, nama dagang, foto, dan materi merek hanya jika Anda memiliki izin yang sesuai.
- Checkout WhatsApp hanya membuka aplikasi/website WhatsApp dengan pesan terisi. Tidak ada pembayaran online, akun pelanggan, database pusat, panel admin, atau sinkronisasi stok otomatis pada versi statis ini.
- Untuk toko produksi, tambahkan backend/database, autentikasi admin, validasi stok, pengelolaan pesanan, kebijakan privasi, syarat layanan, dan metode pembayaran yang sesuai.
